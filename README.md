# Bài tập OOP - Tuần 05a: Quản lý thiết bị Lab

Đây là bài tập thực hành môn Lập trình hướng đối tượng. 
Hệ thống quản lý các thiết bị như Máy tính, Máy in, Máy chiếu trong phòng thực hành.

**Tiến độ thực hiện:** 
- [x] **Ngày 1:** Xây dựng lớp cơ sở `Device` và các lớp dẫn xuất (`Computer`, `Printer`, `Projector`). Đã cài đặt tính chi phí bảo trì.
- [x] **Ngày 2:** 
  - Thêm Interface `INetworkable` cho các thiết bị có thể kết nối mạng.
  - Tách riêng `NetworkPrinter` để xử lý bài toán một số máy in có mạng, một số thì không.
  - Xây dựng lớp `LabRoom` để quản lý danh sách thiết bị trong phòng thực hành.
- [ ] **Ngày 3:** Chờ viết file `main.py` để chạy thử toàn bộ chương trình và nộp.

*Ghi chú: Đã có file chứa câu trả lời lý thuyết về thiết kế interface mạng.*
