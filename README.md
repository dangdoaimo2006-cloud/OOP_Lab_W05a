# Bài tập OOP - Tuần 05a: Quản lý thiết bị Lab

Đây là bài tập thực hành môn Lập trình hướng đối tượng. 
Hệ thống quản lý các thiết bị như Máy tính, Máy in, Máy chiếu trong phòng thực hành.

**Tiến độ:** 
- Đã hoàn thành Ngày 1: Xây dựng lớp cơ sở `Device` và các lớp dẫn xuất.
- Code đang trong quá trình phát triển, còn thiếu phần Network và LabRoom sẽ bổ sung sau.
